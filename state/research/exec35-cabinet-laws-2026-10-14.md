## R350 — bounded-schema validation law (the enum/range upgrade)

Kernel output validation (`validateOutput`, steem@saos-cockpit `mini-services/saos-engine/kernel-isolation.mjs` @ `4f869f6b`) accepts per-field constraint objects beside the legacy type string — **enum / min / max / minLength / maxLength**: enum = array with strict `===` semantics and no coercion; min/max are inclusive numeric bounds; minLength/maxLength are string-length bounds. Every violation fails CLOSED with a precise machine-readable reason (`"signal: value \"long\" not in enum"`, `"confidence: 150 > max 100"`, `"-5 < min 0"`, `"rationale: length 2000 > maxLength 1024"`) — never silent coercion, never a defaulted value. Unknown schema keys are IGNORED (tolerant of spec growth, no noise errors); malformed bounds/enum shapes fail closed; constraints skip absent keys (absence remains a `required[]` matter); legacy string schemas are byte-compatible (all 1663 pre-extension selftest vectors unchanged). **Every persona/agent output that feeds a decision MUST be enum+range-parsed before use** (ai-hedge-fund precedent, 34-c: `signal ∈ {bullish,neutral,bearish}`, `confidence ∈ [0,100]`). A decision pipeline that cannot state its value domains is not a deterministic pipeline.

## R351 — cabinet law (deterministic multi-persona decisions, paper-only)

- **Deterministic aggregation** — blend excludes + counts abstentions and invalids; sign vote bullish=+1/neutral=0/bearish=−1; `netConviction = Σ(sign×confidence/100)/max(1, nonAbstainCount) ∈ [−1,1]`; verdict thresholds are DECLARED constants (BLEND_BUY_THRESHOLD=+0.25 / BLEND_SELL_THRESHOLD=−0.25 ⇒ BUY/SELL/HOLD), never vibes.
- **"Conviction requests, risk disposes"** — risk clamps are hard and non-negotiable: the kill-switch forces HOLD with sizing 0; conviction floors force HOLD; sizing caps clamp |netConviction|-derived sizing; EVERY applied clamp emits a `{clamp, from, to, at}` ClampEvent — no silent pre-capping of the audit trail, no noise event when already flat.
