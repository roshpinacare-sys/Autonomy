## 2. Key engineering findings (synthesized from the three lanes)

1. **Mercury is GENUINELY deterministic — not marketing.** Static `StateGraph`s; routing = pure functions over typed state; the LLM sits entirely upstream (Juno emits validated structured intent). The value pipeline is a fixed 9-stage gate: `resolve_nonce → populate_gas → simulate → policy → approval → idempotency → sign → broadcast → receipt`, with a **default-deny approver** (an approver that always demands approval for value moves unless explicitly injected) and mechanical policy rejections (unlimited approvals, bridge routes, expired quotes, chain mismatch). "1Claw" de-marketed = a **hosted secrets-vault + signing SaaS** (single-vendor custody trust root: raw private keys transit their server → HTTPS → process memory at every sign) — not a protocol.
2. **Zen7's "4-agent settlement" = one process + a shared session dict** (ADK `SequentialAgent` + `tool_context.state["user:*"]` + a session-keyed singleton registry), not agent-to-agent collaboration. Its DB status and payee-notification paths are **fail-open** (empty/failed result still marks SUCCESS and notifies the payee — verified lines). Zen7-Payment-Agent has **exactly one** real fail-closed budget check (`spend_amount > budget → failed` before intent/signing); everything else is prompt-enforced ("DO NOT ASK TO CONFIRM… IMMEDIATELY PROCEED") or schema-only (`AuditEventType.policy_blocked` defined, zero emitters). **moltspay is the real substance**: genuinely fail-closed guards, `requireOperator` (no key configured → endpoint disabled; mismatch → 401), and the **allowance-bounded agent wallet** via EIP-2612 permit (hard value cap + deadline + on-chain nonce — the agent holds no funds).
3. **legion_agi = real substance but modest.** Frozen since 2025-03-06, 0 tests, prompt-glue decision code whose EAT acceptance "gate" is a regex-scraped LLM self-score with a silent 0.5 default; termination = fixed counters; quadratic token burn (all prior output re-pasted every prompt); fallback "experts" carry fabricated MIT/Stanford/CERN backstories. **The spawn-manifest PATTERN is the harvest**: typed 5-field spawn JSON emitted by a local LLM → parse-with-retry → deterministic fallback → hard `MAX_AGENTS` fan-out cap (their only storm guard).
4. **Artificial-Superintelligence (izzuddin-noormy) = VAPORWARE definitively.** 341 lines total, zero code, benchmark placeholders, false DeepSeek-V3 integration claim. Nothing to assess, nothing to borrow, not even a fork to diff.

## 3. Security findings (cross-lane)

- **LLM-output-dependent gates**: aurey's prompt-only tx confirmation (no mechanical approval node); Juno's substring approval heuristics (a model output that omits the 13 phrases never shows an approval keyboard). Both are the exact anti-shape of our dual-key fail-closed gate.
- **moltspay postinstall RCE**: `npm install` downloads a binary CLI from Alipay's CDN at install time — **never install** (opt-out flag exists; the npm hook remains).
- **Zen7 `execute_sign.py` plaintext-key logging**: the entire key interpolated into a ValueError; first/last 10 hex chars logged at INFO every startup (shape finding — no key exists in the repo).
- **`curl|bash` installer culture**: aurey-mcp's published one-liner is currently corrupted (mangled package name `aurey-wallet-mcpermes]`) — live evidence that pipe-to-shell installers rot; plus a vendored duplicate of aurey inside aurey-mcp (patch-divergence risk).
- **Licensing**: 4/5 Pantheon repos have NO license → **patterns-only harvest, NO code fork** (aurey-mcp MIT is the single exception). Zen7 repos are Apache-2.0/MIT.
- **Supply-chain scan clean otherwise**: zero hardcoded credentials across all 10 repos (all 64-hex literals are keccak topics/typehashes or README dummies); no obfuscated install hooks in the Zen7/Pantheon Python repos; unpinned `>=` floors on fast-moving agent stacks.

## 6. Rejects recorded (with reasons, not contempt)

1. **1Claw / any hosted-custody SaaS** — single-vendor trust root; keys transit a third-party server at every sign. Violates the keys-never-leave-custody law.

3. **Fail-open status paths** (Zen7 settlement SUCCESS on empty/failed result) — verdicts must be derived from the result value; "no result" means FAILED.
4. **Install-time network fetches** (moltspay postinstall CDN binary; aurey-mcp curl|bash) — supply-chain class the fleet never touches.
5. **Unlicensed code adoption** (4/5 Pantheon repos) — legally undistributable; patterns only.
