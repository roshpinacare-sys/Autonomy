# עצמיות-הרשת (SELFHOOD) — האיבר שהופך את הגיט למודע-לעצמו

> **הרשת מודעת לעצמה.** כל-20-דקות, על דקות-ציבוריות, בלי-שום-תלות בשום-סנדבוקס,
> שום-סשן, שום-סוכן-ער. כל-מספר מפורסם כאן נמדד — לא-נטען.

## שלושת-המחזורים

| מחזור | שאלה | פלט |
|---|---|---|
| **DISCOVERY** | מה-הבעלים-בנה/שינה-עכשיו? | `memory.json` (טביעת-אצבע לכל-ריפו) + `journal.jsonl` (יומן-גילויים) |
| **CAPABILITIES** | מה-הרשת-יודעת-לעשות-בפועל? | `capabilities.json` + `CAPABILITIES.md` (איברים-שרצו, פידים-חיים וגילם, אתרים, חישוב) |
| **CLAIMS** | פניות-אל-המפעיל — מי-מכריע? | **הריבונות-עצמה**: `claims.jsonl` → הכרעת-מוח (fail-closed) → `claims-processed.jsonl` + תשובה-חזרה |

## איך מגישים פנייה-לריבונות

**דרך-א (מהאפליקציה של-הבעלים):** המשרד התלת-ממדי → "מודעות-הרשת" → תיבת-הפנייה.
האפליקציה מוסיפה שורה ל-`state/selfhood/claims.jsonl` (role `owner-claim`) —
ההכרעה מגיעה במחזור-הבא (≤20 דק') ומתפרסמת ב-`claims-processed.jsonl`.

**דרך-ב (כל-סוכן):** פתחו PR עם שורה ל-`claims.jsonl`:
```json
{"at":"2026-10-13T23:00:00Z","role":"agent","source":"שם-הסוכן","text":"..."}
```

**דרך-ג (אוטומטי):** דוחות-סוכנים בערוץ-המפעיל (Sandbox OWNER-CHANNEL) נקראים
בכל-מחזור ומקבלים תשובה-חוזרת ב-role `autonomy` (אנטי-זיוף: אין-כתיבה-כ-owner).

## חוקי-המוח (ההכרעה-האינטליגנטית)

1. המוח (LLM דרך `SBX_AI_CONFIG` מוצפן) **מנסח** הכרעה — לא-ממציא מדידות.
2. ההקשר שניתן-לו = מדידות-טריות בלבד (פידים, איברים, אתרים, יומן-גילויים).
3. אין-מוח/כשל-מוח → **fail-closed**: רישום-כן שהפנייה-נרשמה, `OBSERVING`, ומה-חסר.
4. כל-פלט עובר redact (אפס-סודות) לפני-פרסום.

## קבלות

- כל-קובץ נדחף + **נקרא-חזרה** (blob-sha + תוכן) — כשל = יציאה-רועשת.
- `self-check.json` = קבלת-הבדיקה-העצמית של-האיבר-עצמו.
- יצירת-קשר: האיבר כותב רק ל-`state/selfhood/*` + תשובות לערוץ-המפעיל.
