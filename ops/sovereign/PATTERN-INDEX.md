### 3. reaper-law (חוק-הקציר)
מנגנון: צאצאי-המעטפת של הסוכן (גם-setsid) נקצרים תוך-דקות; רק צאצאי-next-server/watchdog שורדים — הכל חייב לרדת מ-next-server. מבחן: PPID-הוכחה בכל-הקמה.

### 4. port-probe-liveness (דופק-משקר)

### 5. interactivity-law

**מקור**: Task 12-a-השלמה (גל-102, root: EADDRINUSE:::3000 + RSC-תקוע)

### 11. memory-discipline-4-layers
מנגנון: (1) תקרת-זיכרון לכל-ספאון שלנו (1024MB) (2) memWatch קוצר-בלוט-חי-לפני-ה-kernel (RSS/pressure + SIGTERM→SIGKILL-escalation + cooldown-שורד-דורות) (3) reap-before-spawn (קבורת-גוויה SIGTERM-עמידה שמחזיקת-.next/dev/lock) (4) שרשרת-החיה dev-keeper+guardian+economy-reviver (<1ש' נמדד).
**מקור**: Task 15-a/b/d (גלים 104-108, G23-G26 — OOM×3 + לולאת-חנק-אינפיניטית)

### 12. turnover-order

### 29. public-surface-secret-scan (אפס-סודות-בפומבי)
- **מקור**: R319 · P0 נמדד-חי — raw.githubusercontent הגיש .secrets/* מ-steem הציבורי (HTTP 200) בזמן-שהצי הניח-שהריפו-פרטי. נסגר: קילוף-tip → 404 מאומת ×4.
- **מנגנון**: כל-דחיפה-למשטח-ציבורי עוברת-סריקת-שמות-ותבניות-סוד; ריפו-פרטי ≠ הנחה-לכתחילה — נבדק-בפועל (unauth git = המבחן-המכריע, לא-ה-API).
- **מבחן-הפרכה**: `curl raw.../steem/main/.secrets/<מפתח-הקודקוד>.key` (השם-המדויק-נגזר-בזמן-ריצה-מהכספת — אינו-בעץ-הציבורי, חוק-הrefs) חייב-404 לנצח; unauth `git ls-remote` לריפו-ציבורי-לכאורה חייב-להיכשל.
